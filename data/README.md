# 固定合成订单样本

[项目首页](../README.md) · [原始 CSV](raw/orders.csv)

40 条合成订单、7 列，无真实个人信息；原始样本保持不变，测试变体只在临时目录建立。预期总数 40、正常 29、异常 11、问题 11、质量分 72.50%。

| 字段 | 含义与业务规则 |
| --- | --- |
| order_id | 订单号，非空且应唯一；所有重复参与行均标记 |
| customer_id | 虚构客户编号，必填 |
| product_id | 虚构商品编号，必填 |
| quantity | 十进制整数，1～100，含边界 |
| unit_price | 普通十进制单价，0.01～10000.00，含边界 |
| order_time | 真实本地日期时间 yyyy-MM-dd'T'HH:mm:ss |
| status | PENDING、PAID、SHIPPED、CANCELLED，大小写敏感 |

项目使用成熟 CSV 解析器处理 UTF-8、引号、转义和跨行字段；固定样本本身保持简单。表头可重排但七字段各出现一次，不接受额外列名或重复表头。缺少/多出数据列会报告结构问题，无法恢复的引号格式会使任务失败，不静默丢行。

范围是演示业务约定，不代表所有电商业务。ERROR/WARNING 都计入异常记录，问题数与异常记录数分别统计；质量分不表示自动修复准确率。
