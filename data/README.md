# 固定合成订单样本

[项目首页](../README.md) · [原始 CSV](raw/orders.csv)

40 条合成订单，7 列，没有真实个人信息。原始样本不会被改动，测试用的变体只在临时目录里生成。预期结果：总数 40、正常 29、异常 11、问题 11、质量分 72.50%。

| 字段 | 含义和规则 |
| --- | --- |
| order_id | 订单号，非空且应唯一；所有重复的行都会被标记 |
| customer_id | 虚构的客户编号，必填 |
| product_id | 虚构的商品编号，必填 |
| quantity | 十进制整数，1 到 100，含边界 |
| unit_price | 十进制单价，0.01 到 10000.00，含边界 |
| order_time | 真实存在的本地日期时间，格式 `yyyy-MM-dd'T'HH:mm:ss` |
| status | PENDING、PAID、SHIPPED、CANCELLED，区分大小写 |

CSV 用成熟的解析器读取，支持 UTF-8、引号、转义和跨行字段，样本本身保持简单。表头顺序可以调整，但七个字段必须各出现一次，不接受多余的列名或重复的表头。数据列缺少或多出会报告为结构问题，无法恢复的引号格式会让任务失败，不会悄悄丢掉行。

这些是演示用的业务约定，不代表所有电商场景。ERROR 和 WARNING 都计入异常记录，问题数和异常记录数分别统计。质量分只表示正常记录的占比，与自动修复的准确率无关。
