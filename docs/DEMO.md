# 三分钟演示与匿名截图

先执行 README 构建/启动命令，默认仅访问 http://127.0.0.1:8080。示例为固定 40 条合成订单，不含真实个人信息；原 CSV 不修改。

1. 网页点击“导入模拟订单”，记录 datasetId；也可上传 data/raw/orders.csv。
2. 点击“开始检测”，查看任务和 JSON/HTML。预期总数 40、正常 29、异常 11、问题 11、质量分 72.50%。首项问题定位数据记录 7 / 物理行 8。
3. 解释记录与问题数量不同，一行可触发多条规则；查看必填、重复、范围、日期等分类。
4. 上传空 CSV，任务应 FAILED / EMPTY_FILE；读取该报告应 409，而非空的成功报告。
5. 正常关闭并用相同数据库/上传目录重启，查询旧任务；报告、失败历史和文件再检测仍存在。

可复现自动验收（先启动服务）：

```bash
python3 scripts/demo-check.py create --state .setup/demo-state.json
# 正常停止并重新启动同一服务后：
python3 scripts/demo-check.py verify --state .setup/demo-state.json
```

API 请求、JSON 和错误示例见 [API](API.md)；真实执行范围见 [验收](VALIDATION.md)。本项目不提供断电灾备、生产备份恢复或多实例安全承诺。

截图前用无账号访客浏览器窗口，仅保留本机页面内容。第一张展示样本报告及计数，第二张展示错误定位，第三张可选 EMPTY_FILE 任务详情。裁掉浏览器账号、书签、桌面路径和终端历史。不要上传 .env、数据库或原始浏览器完整截图。本候选提供步骤，未附带个人桌面截图。
